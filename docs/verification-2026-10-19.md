# mps-growth 검증 기록 — 2026-10-19

대상: 복원된 @growthai를 복제한 mps-growth. 독립 저장소: https://github.com/jungwooki/mpsgrowthai

## 수정

- 시작.command: 다른 컴퓨터의 복제 .venv 대신 Python 3.12와 로컬 캐시 실행 환경 사용. 의존성 변경 시 설치 갱신. PORT 및 GROWTH_NO_BROWSER 지원.
- Docker: Python 3.12로 통일, workspace.html 및 headquarters.html을 빌드 대상에 포함.
- API 키, 로컬 대화 기록, 가상환경, 비공개 원본, 실행 결과를 Git에서 제외. 이전 Git 이력 없이 독립 초기 커밋으로 게시.
- 복사된 기존 Vercel 연결은 로컬 캐시 백업으로 이동하여 독립 프로젝트의 오배포 방지.
- README 실행 안내와 실제 API 검증 스크립트의 기본 모델 처리 수정.

## 확인 결과

- 기존 Python 테스트: 129개 통과.
- Docker 파일 포함 회귀 검사 추가 후 배포 관련 테스트: 8개 통과. 전체 고유 Python 테스트 130개.
- JavaScript 테스트: 5개 통과 (메모 추출, 업로드 재시도 등).
- 수정된 시작.command로 서버 실제 기동, /healthz HTTP 200.
- 브라우저에서 예시 입력 → 기본 계산 → 성장도표·BMI·성장속도 표시 성공. 검사 중 오류/경고 콘솔 로그 없음.
- 자료실 11개 항목 표시 및 로컬 원본 11개의 크기·SHA-256 일치 확인.
- 실제 OpenAI API: 환자나 참고자료를 전송하지 않는 가상 빈 이미지로 HTTP 200, 구조화 응답 및 근거 부족 시 판단 보류 검증 통과.
- /.env, /ing.txt, /.git/config 접근은 모두 HTTP 404.
- 업로드 대상에서 설정된 비밀값 및 일반적인 API 키 패턴이 발견되지 않음.

## 운영 범위 및 남은 설정

- 이 기록은 로컬 기능 및 자동 테스트 검증이며 임상 정확성 검증이 아님.
- 복원된 버전이므로 선수별 누적 결과 데이터베이스는 없음.
- 현재 로컬 APP_USERNAME/APP_PASSWORD 및 센터 계정 미설정. 인증·권한 기능은 테스트용 계정으로 자동 테스트했으며 실제 운영 계정은 별도 설정 필요.
- S3 업로드 및 비용 관리 저장소 미연결. 실제 S3 통신은 검증하지 않았음.
- GitHub에는 참고자료 원본이 없음. 온라인 AI 운영에는 비공개 원본 연결과 서버 환경변수가 필요.
- 기존 Vercel 배포 보호 설정은 원본 없는 GitHub 빌드를 건너뜀. 이 업로드만으로 온라인 서비스가 새로 배포되지는 않음.
- Docker 실행 도구가 없어 컨테이너 빌드/실행은 미검증. 파일 포함 및 버전 정합성은 회귀 검사로 확인.
- PyMuPDF/Starlette 의존성의 deprecation 경고 6개가 남아 있음. 테스트 실패는 없음.
